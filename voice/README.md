# Записи голоса преподавателя

Сюда кладутся записи для длинных видео и презентации курса:

- `seriya_09.*`, `seriya_10.*`, `seriya_11.*` — Мединский курс, серии 9–11
  (сцены по порядку, между сценами пауза 3 сек);
- `prezentaciya.*` — видео-презентация курса «Алфавит + таджвид».

Формат любой: m4a, mp3, ogg, wav, opus.
