# Пилотный урок: как запустить (0 ₽)

## Что это
Автоматический видеоурок: учитель Марьям, английский, урок 1 «Приветствие».
Из одного JSON-файла генерируется всё: слайды, озвучка (русский + английский голос), готовое видео lesson.mp4 (~6 минут с реальной озвучкой).

## Установка (один раз)
1. Python 3.10+ (python.org)
2. FFmpeg: в PowerShell выполнить `winget install ffmpeg` (или скачать с ffmpeg.org и добавить в PATH)
3. Библиотеки:
   ```
   pip install edge-tts pillow
   ```

## Запуск
```
python make_lesson.py lesson_001.json
```
Результат: `build/lesson_001/lesson.mp4`

Внимание: озвучка идёт через серверы Microsoft (бесплатно, без ключей),
нужен интернет. Из России/Казахстана работает без VPN.

## Голоса
- Марьям (русский): ru-RU-SvetlanaNeural
- Английские фразы: en-GB-SoniaNeural (британское произношение)
- Хадиджа для другого канала: женский русский голос в edge-tts только один
  (ru-RU-SvetlanaNeural), различать учителей можно скоростью/тоном (rate/pitch)
- Арабский (для Мединского курса): ar-SA-ZariyahNeural

Послушать все голоса: `edge-tts --list-voices`

## Как сделать следующий урок
Скопируй lesson_001.json → lesson_002.json, поменяй содержимое слайдов
и текст speech. Структура:
- lines — то, что НА слайде
- speech — то, что Марьям ГОВОРИТ (сегменты ru/en озвучиваются разными голосами)

Дальше этот JSON будет писать Gemini API по шаблону — но сначала
проверь пилот руками и послушай результат.

## Вертикальные нарезки (TikTok / Shorts / VK Клипы)
```
python make_shorts.py lesson_001.json
python make_shorts.py arabic_001.json
```
Результат: build/<урок>/shorts/ — ролики 9:16 по 25–55 сек
(один содержательный слайд = один ролик) + рядом .txt с готовой
подписью и хештегами для поста. Озвучка переиспользуется из
собранного урока, поэтому нарезка делается за секунды.

## Автопостинг (каждый день сам)
Скрипт `autopost_daily.py` за один запуск постит: 1 полный урок на
YouTube + 1 нарезку в TikTok. Что уже выложено, помнит в post_log.json.

### Настройка YouTube (один раз, ~15 минут, бесплатно)
1. Зайди на https://console.cloud.google.com (аккаунт Google канала)
2. Создай проект (любое имя) → в поиске найди «YouTube Data API v3» → Enable
3. «OAuth consent screen» → External → заполни имя и почту → в
   «Test users» добавь свою почту
4. «Credentials» → Create Credentials → OAuth client ID → тип
   «Desktop app» → скачай JSON → переименуй в client_secret.json →
   положи в эту папку
5. `pip install google-api-python-client google-auth-oauthlib`
6. Первый запуск `python autopost_daily.py` откроет браузер — разреши доступ
Нюанс: пока Google не проверил приложение, YouTube может ставить видео
private — открой их в YouTube Studio одной кнопкой. После проверки
(бесплатная форма) всё публикуется сразу.

### Настройка TikTok (честно)
Полный автомат требует своё приложение на developers.tiktok.com
(Content Posting API) + проверку TikTok; до проверки видео уходят
только «приватными». Поэтому по умолчанию скрипт работает в полуручном
режиме: каждый день кладёт очередную нарезку с готовой подписью в папку
TIKTOK_TODAY и открывает её — остаётся перетащить в tiktok.com/upload
(30 секунд). Получишь токен API — положи его в tiktok_token.json:
{"access_token": "act.xxx"} — и станет полностью автоматически.

### Расписание на каждый день (один раз)
В PowerShell от имени администратора:
```
schtasks /Create /SC DAILY /ST 10:00 /TN "UrokiAutopost" /TR "'c:\Users\lima2\Downloads\урок английский тест\autopost_daily.bat'"
```
Каждый день в 10:00 будет уходить очередной урок и нарезка.
Проверить без публикации: `python autopost_daily.py --dry-run`
